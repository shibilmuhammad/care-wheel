# Carewheel (carewheel.in)

> **Life moves. We're here to protect it.**

A modern, trustworthy insurance guidance and advisory website for Kerala, helping individuals and families understand and select the right health and vehicle insurance without confusion or sales pressure.

## Features
- **Visual Identity**: Bespoke 3D sculptural visual concept (*"The Hand That Protects Every Journey"*) seamlessly blended into the background.
- **Health & Vehicle Insurance**: Clear policy guidance, waiting period explanations, cashless network hospital clarifications, and vehicle claims support.
- **Founder & Personal Advisory**: Direct advisory desk led by founder **Rajilal**, based in Thulattumnada, Kakkuni 673507 (Kerala).
- **Direct Contact & WhatsApp**: 1-click WhatsApp pre-filled enquiries (`+91 97447 34153`) and direct call actions.
- **Statutory Transparency**: Clear disclosures adhering to IRDAI guidelines.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Fonts**: Plus Jakarta Sans

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
